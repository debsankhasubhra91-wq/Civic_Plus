# 🇮🇳 CivicPulse - National Road & Waste Redressal Platform

> A citizen-first civic empowerment and grievance redressal web platform for reporting and resolving road hazards, potholes, and public waste dumps across Indian states.

---

## 🌟 Highlights & Features

- **🛣️ Road Hazard & Pothole Reporting**: Citizens can snap photos and lodge reports for potholes, road cave-ins, broken asphalt, and sunken manholes with exact GPS locations and landmarks.
- **🗑️ Waste & Public Sanitation Reporting**: Report overflowing municipal garbage bins, illegal plastic dumps, and clogged storm drains.
- **👍 Community Upvoting & Priority Ranking**: Upvote urgent issues to amplify community voice and escalate them directly to Municipal Chief Engineers and PWD officers.
- **🔍 Pan-India State & Area Filtering**: Filter issues across **all 28 States and 8 Union Territories** of India, select specific cities, and search by area / colony name in real time.
- **🗺️ Interactive Geotagged Map**: Explore live grievances mapped with custom color-coded pins (Orange for Roads, Emerald/Teal for Waste) on an interactive Leaflet map.
- **✨ Official Government Redressal Timeline & Before/After Proof**: View step-by-step progress (*Reported ➔ Triaged ➔ In Progress ➔ Resolved*) and compare before vs after repair images.
- **🏛️ Authority Mode Simulator**: Simulate municipal/PWD officers inspecting, updating status, and uploading resolution proof photos.
- **🎨 Premium Pure-White Aesthetic**: Crisp white typography, frosted glass accents, subtle slate borders, and fluid Framer Motion animations.

---

## 🛠️ Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + PostCSS
- **Animations**: Framer Motion + Canvas Confetti
- **Maps**: Leaflet + React-Leaflet + OpenStreetMap
- **Icons**: Lucide React
- **Persistence**: LocalStorage with realistic Pan-India seed dataset

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/your-username/civicpulse-india.git
cd civicpulse-india
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

The application will be accessible at `http://localhost:5173`.

### 4. Build for production
```bash
npm run build
```
